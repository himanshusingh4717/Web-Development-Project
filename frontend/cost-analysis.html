Cost Overrun Formula

Cost overrun measures the percentage by which the actual project cost exceeds the initial budget.

Cost Overrun (%) =

[(Actual Cost − Initial Budget) / Initial Budget] × 100
Example

Initial Budget: ₹ 500 Cr

Actual Cost: ₹ 620 Cr

24% Overrun
